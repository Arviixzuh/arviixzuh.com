~ OVERVIEW ~

Desktop and web application for business management providing control over inventory, warehouses, suppliers and customers, with integrated invoicing and multi-branch support.

~ PLANNING ~

Built using Agile methodology. Hybrid architecture (Electron for desktop and web), MySQL and MongoDB databases, backend in Java with Spring. CI/CD via GitHub Actions with separate dev/prod environments.

~ FEATURES ~
  • Real-time inventory and warehouse management with multi-location support.
  • CRM for suppliers and customers with transaction histories and metrics.
  • Sales tools and analytics for reports and KPIs.
  • Fiscal integration for automated electronic invoicing using ARCA.
  • HR module for employee records and role assignments.
  • Data import/export to Word, PDF and Excel.
  • AI agent for data extraction and analysis.
~ IMPACT ~

Reduced management times, more accurate reporting and high adoption due to simplicity; efficient compliance with fiscal regulations.
